# Contributing

Thanks for improving Adrex Verity.

## How to contribute

1. Fork the repository.
2. Create a branch.
3. Make your change.
4. Test the extension in Chrome.
5. Submit a pull request.

## Good first issues

- Improve claim detection
- Add more trusted domains
- Improve source relevance scoring
- Add new report formats
- Improve accessibility
- Add translations

## Rules

- Do not add scraping of signed-in AI websites.
- Do not collect user data.
- Do not claim an answer is definitively true.
- Keep the extension local-first.
