Install Adrex Verity Lite

  1. Open the Adrex Verity GitHub repository.
  2. Click the green Code button.
  3. Click Download ZIP.
  4. Extract the downloaded ZIP file.
  5. Open Chrome or Edge and go to chrome://extensions or edge://extensions.
  6. Turn on Developer mode.
  7. Click Load unpacked.
  8. Select the inner folder named adrex-verity-lite.
  9. Pin Adrex Verity to your toolbar and paste any AI answer to verify it.
Honest disclaimer: Adrex Verity does not prove an answer is true and does not provide medical, legal, financial, or safety advice. It helps you check evidence and make more careful decisions.
